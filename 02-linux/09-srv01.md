# SRV01: el servidor Linux del laboratorio

**Paso 9 del plan** · VM creada el 07/11/2026 · Revisada el 17/11/2026

---

## Qué problema resuelve

El lab necesita un servidor Linux real para practicar todo el Bloque 2 (filesystem, permisos, logs,
systemd, hardening) y para ser, más adelante, el segundo endpoint que manda logs al SIEM. Se
administra como un servidor de verdad: sin entorno gráfico y solo por SSH.

## Cómo lo abordé

| Propiedad | Valor |
|---|---|
| Sistema | Ubuntu Server 26.04 LTS, sin entorno gráfico |
| VM | Generación 2 · 2 GB de RAM **estática** (regla del lab para Linux en Hyper-V) |
| Disco | LVM, 37 GB para `/` |
| Red | `LAB-SERVIDORES` · IP fija `10.10.10.20/24` · gateway `10.10.10.1` (`FW01`) |
| DNS | `10.10.10.10` (`DC01`), dominio de búsqueda `lab.interno` |
| Integración con Hyper-V | `linux-cloud-tools-virtual`, para que Hyper-V vea la IP y pueda apagar la VM de forma ordenada |

### Acceso por SSH con clave

Desde la Mac, a través de Tailscale y `FW01`:

```bash
ssh-copy-id srv01@10.10.10.20     # una sola vez, con la contraseña
ssh srv01@10.10.10.20             # de ahí en adelante, solo con la clave
```

`ssh-copy-id` copia la clave pública de la Mac a `~/.ssh/authorized_keys` en el servidor, con los
permisos correctos. La clave privada nunca sale de la Mac.

## Cómo lo verifiqué

| Prueba | Resultado |
|---|---|
| SSH con clave desde la Mac | ✅ |
| Métodos que ofrece el servidor a un usuario sin clave (`ssh -v`) | Al principio, `publickey,password`. Ver [Paso 23](23-hardening.md) |
| `SRV01` → internet | Bloqueado por `FW01`, como dice la matriz |
| Hyper-V ve la IP de la VM (`Get-VMNetworkAdapter`) | ✅ después de instalar las herramientas de integración |

## Qué aprendí

- **Deshabilitar la contraseña en `sshd_config` no alcanza si no lo verificás desde afuera.** El
  servidor seguía aceptando contraseña: la explicación está en el [Paso 23](23-hardening.md).
- Con la red segmentada, **instalar un paquete es un cambio de firewall**: Servidores no tiene
  salida a internet, y hay que abrirla a propósito y cerrarla después.
