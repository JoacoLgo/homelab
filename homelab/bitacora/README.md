Una entrada por semana. Sin excepción.

**Por qué existe esta carpeta:** la diferencia entre "estudié 570 horas" y "puedo probar que
estudié 570 horas". Un reclutador no puede verificar horas de video; sí puede leer un registro
semanal de decisiones, problemas y soluciones.

Cada entrada responde cuatro preguntas: **qué hice**, **qué se rompió**, **cómo lo resolví**,
**qué aprendí**.
